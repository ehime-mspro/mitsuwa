# 保存の Ajax の 401 を日本語にする Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ほかの画面でパスワードを変えたあとなどに基幹の保存（GET 以外）の Ajax が 401 になったとき、英語の `Unauthenticated.` や番号ではなく日本語の理由を出す。

**Architecture:** サーバー（`bootstrap/app.php` の `AuthenticationException` の render）が、決裁の URL に加えて基幹の GET 以外の JSON の 401 にも決裁と同じ文を返す。サーバーの文をそのまま出す 26 か所は画面を変えない。番号だけの 8 か所は 419 と同じく 401 でもサーバーの文を出す。原価のカードは「この文なら、ログインが切れた側」と見分けて今の文を保つ。

**Tech Stack:** Laravel 12（PHP 8.3）・Blade の中の素の JS / Alpine.js 3・PHPUnit 11（画面の JS は `Tests\Concerns\DrivesAlpineFetch` で node の vm で動かす）

**Spec:** `docs/superpowers/specs/2026-11-18-save-ajax-401-design.md`

## Global Constraints

- 文は 1 字も変えない: `ログインが切れました。ログインし直してから、もう一度やり直してください。`（決裁の URL の今の文と同じ）
- **GET の JSON の 401 は `Unauthenticated.` のまま**（`_partials/_ajax_get_failure` が英語の 401 を見分けている）
- 決裁の URL の応答は変えない。`ApprovalJsonExpiredSessionTest` は説明文（docblock）だけ直し、触る前に `ListAgents` で「社内決裁申請」の会話が動いていないことを確かめる
- 作業場所は `.claude/worktrees/save-ajax-401`（枝 `save-ajax-401`）。`.env` を作らない・`git stash` を使わない
- テストは作業場所の cwd で:
  `APP_KEY="base64:$(openssl rand -base64 32)" /opt/homebrew/opt/php@8.3/bin/php -d opcache.enable_cli=1 -d opcache.memory_consumption=256 vendor/bin/phpunit --display-phpunit-deprecations`（1 本だけなら末尾にファイルか `--filter`）
- 応答・コメントは日本語、コードの名前は英語
- コミットは Conventional Commits、本文の末尾に空行を挟んで `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- `13.x` への早送り・push・`./deploy.sh` は利用者の明示の指示があったときだけ（この計画には含めない）

## Review Focus

1. ログインの無い保存（認証の確かめで断られる。論理削除された人と同じ道）も、`AuthenticateSession` の道と同じ日本語の 401 になる → Task 1 の `test_a_save_without_a_login_gets_the_same_reason`
2. ふつうのフォーム（JSON を求めない POST）は今どおりログイン画面へ転送される → Task 1 の `test_a_form_save_still_goes_to_the_login_page`
3. GET の JSON は英語の 401 のまま（GET の部品の案内が保たれる）→ Task 1 の `test_a_read_keeps_the_english_401`（と既存の 4 本の `GetAjaxFailureTest` が緑のまま）
4. 原価のカードで、無効にされた人（日本語だがログイン切れではない 401）は今どおり「理由＋何もしていない」→ 既存の `CostCardAccessErrorTest` の「無効にされた」6 件が緑のまま（Task 1 Step 9）
5. 401 でも本文が JSON でない（HTML が返った）ときは番号つきの文 → Task 2 の `test_a_rank_change_after_the_password_changed_elsewhere_says_why` の 3 つめの見本

```php
public function test_a_save_after_the_password_changed_elsewhere_gets_the_reason_in_japanese(): void
{
    foreach (['POST', 'PUT', 'PATCH', 'DELETE'] as $method) {
        $this->actingAs($this->user)->getJson('/_probe_save')->assertOk();   // パスワードの控えを作る
        $this->changePasswordElsewhere();
        $this->json($method, '/_probe_save')->assertUnauthorized()->assertExactJson(['message' => self::SIGNED_OUT_JSON_MESSAGE]);
        $this->assertGuest();
    }
}

public function test_a_save_without_a_login_gets_the_same_reason(): void
{
    $this->postJson('/_probe_save')->assertUnauthorized()->assertExactJson(['message' => self::SIGNED_OUT_JSON_MESSAGE]);
}

public function test_a_read_keeps_the_english_401(): void
{
    $this->actingAs($this->user)->getJson('/_probe_save')->assertOk();
    $this->changePasswordElsewhere();
    $this->getJson('/_probe_save')->assertUnauthorized()->assertExactJson(['message' => 'Unauthenticated.']);
}

public function test_a_form_save_still_goes_to_the_login_page(): void
{
    $this->actingAs($this->user)->get('/_probe_save')->assertOk();
    $this->changePasswordElsewhere();
    $this->post('/_probe_save')->assertRedirect(route('login'));
}

public function test_a_deactivated_user_keeps_the_inactive_reason(): void
{
    $this->actingAs($this->user)->getJson('/_probe_save')->assertOk();
    $this->deactivateSignedInUser();
    $this->postJson('/_probe_save')->assertUnauthorized()->assertExactJson(['message' => self::INACTIVE_JSON_MESSAGE]);
}
```
