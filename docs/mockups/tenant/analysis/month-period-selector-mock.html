③ 仕様メモ（確認してください）

・セレクトは1つのまま。「全期間」→「期間」グループ（直近2/4/6/8年）→「年度」グループ（単年・降順）の3ブロック構成。<optgroup> で見出しを付けています。
・直近N年 = 今年から暦年で遡ってN年（今年を含む）。今日は2026-07-15 なので直近2年 = 2026年・2025年です（ご質問の選択肢で「2025と2024」と書いたのは私の誤記でした）。データが無い年も0件として含みます。
・このモックのデータは本番の実分布（全期間124件）をそのまま使い、年内訳だけ仮に置いています → 全期間124 / 直近8年121 / 直近6年97 / 直近4年65 / 直近2年29。
・初期値は「全期間」＝今の見た目のまま。総計バッジは選択に連動。年別集計カードは変更しません。
・2026年は年の途中（7月時点）なので8月以降は0件です。実データでも同様の見え方になります。
