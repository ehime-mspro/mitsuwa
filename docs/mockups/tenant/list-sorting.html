テナント管理 一覧の並び替え

ヘッダーを実際に押せます。降順 ▼ → 昇順 ▲ → 既定に戻る の 3 状態と、「—」が常に末尾へ回ること、 同点の行が既定順で並ぶことを確認してください。上のバーに、そのとき生成される URL が出ます。

1物件一覧 /tenant/properties

並び替えできるのは 入居率・賃料収入 の 2 列。非稼働の物件は値が「—」なので常に末尾へ回ります。

非稼働の 2 件が常に一番下に居ることを確認してください。「入居率が低い順」で見たいのは 稼働中で入居率が低い物件であって、そもそも計算対象外の非稼働物件ではないためです。

2部屋一覧 /tenant/units

並び替えできるのは 面積・家賃・月額合計 の 3 列。共益費・ゴミ代・駆除代・敷金には矢印が出ません。 実画面は横幅 1500px で横スクロールします（ここでも同じ幅にしてあります）。

URL /tenant/units
← 横にスクロールできます →
物件名 部屋名 面積 ステータス 家賃 共益費 ゴミ代 駆除代 月額合計 敷金 店舗名 操作
同点の行に注目してください。「三番町ビル 2F201」と「3F301」は面積・家賃・月額合計がすべて同じ、 「湊町テラス 2F201」と「千舟町スクエア 1F101」は月額合計が同じ 0 円です。 どの列で並べても、この同点どうしは常に既定順（物件→階→号室）で並びます。 ここが不定だと、実画面の 8 ページに切ったときに同じ部屋が 2 ページに出たり、どのページにも出なくなったりします。
「湊町テラス 2F201」は面積が未入力（—）なので、面積で並べたときだけ末尾へ回ります。 家賃・月額合計は 0 円という実際の値なので、末尾扱いにはせず 0 として並びます。
