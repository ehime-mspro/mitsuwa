ZEAL 経営試算表 — モック一覧

予算機能 + 未確定月の予測表示の UI モック。各カードをクリックして確認してください。

1詳細画面（show）

show-with-budget.html
月別マトリクス（未確定月=灰色イタリック、通期列=実績+予測の合算）+ 通期予実比較サマリー。 ヘッダーの「実績 / 予算 / 比較」ボタンで表示が切り替わる。
✓ 3モード切替 ✓ 未確定月予測 ✓ 通期サマリー

2編集画面（edit）

edit-with-budget.html
「実績編集」/「予算編集」タブで入力対象を切替。緑(実績)/青(予算)のテーマ色。 Phase 5 のリアルタイム計算は両モードで動作。
✓ 実績/予算 タブ切替 ✓ テーマ色変更

3実績反映モーダル

sync-actuals-modal.html
完了月のみデフォルト反映。「当月（5月）も反映する」チェックで暫定値を含めるかオプション切替。 プレビューも変更状況に応じて行表示が変わる。
✓ モーダル ✓ 当月オプション切替

4通期サマリー（拡大表示）

comparison-summary.html
19 項目 × 4 列（実績計 / 予算計 / 差異 / 達成率）。カテゴリグループ化（固定費・売上連動費・変動費）+ 達成率バー（緑/黄/赤）。
単独表示（静的） 達成率バー
📌 確認ポイント:
• ① 詳細画面: ヘッダー右の「実績/予算/比較」ボタンをクリック → 表の内容が切り替わるか、比較モードでサマリーが強調されるか
• ② 編集画面: 上部「実績編集」/「予算編集」タブをクリック → テーブルとテーマ色が切替わるか
• ③ 実績反映モーダル: 黄色枠の「当月（5月）も反映する」チェック → プレビュー行と反映対象月数が変わるか
• ④ 通期サマリー: 各項目の差異・達成率の表示、達成率バーの色分けが分かるか
