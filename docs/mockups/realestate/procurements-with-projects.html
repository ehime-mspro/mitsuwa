この画面の仕様（提案）

一覧に出るもの 仕入れ案件（re_procurements）＋ 分譲地（re_projects）を混在表示。情報入手日の降順で1本のリストにマージし、20件/ページで送る。「全 N 件」は合算値。
物件種別 分譲地の行は他の種別と同じ素のテキストで「分譲地」と表示。絞り込みセレクトでは「物件種別: 全て」の直下＝実種別の先頭に「分譲地」を置く。
⚠ RealEstatePropertyType enum には追加しない。追加すると仕入れ案件の登録フォーム（_form.blade.php）の選択肢にも出てしまい、「物件種別＝分譲地の仕入れ案件」という不正データを作れてしまうため。一覧フィルタ専用の擬似値 project として扱う。
取引種別 分譲地には該当データが無いので「—」。取引種別で絞り込んだときは分譲地は結果から外れる（＝該当なしのため）。
区画数 専用の列は設けず、分譲地の行の物件名の下に小さく「区画 成約数 / 総数」を添える。仕入れ案件の行には何も出さない（サブ行そのものが無い）。区画が0件の分譲地は「区画 0 / 0」。
区画ボタン 分譲地の行のみ区画一覧へのリンクを表示（区画0件でも表示＝そこから登録するため）。仕入れ案件の行は「—」。
ステータス 行のバッジは各モデル固有のラベル・色のまま（分譲地は「検討」「不成立」、仕入れは「査定・検討」「不成約」）。バッジをクリックしての即時変更も、それぞれ既存の更新APIへ送るので今の挙動が変わらない。
絞り込みセレクトは仕入れ案件側のラベルを採用し、内部で分譲地側の同値へマッピングする（「販売済」は仕入れ sold と分譲地 sold_out の両方にヒット／「現地調査」は仕入れ案件のみ）。既定の「進行中のみ」は、仕入れ＝不成約・販売済を除外、分譲地＝不成立・販売済を除外。
リンク先 分譲地の「詳細」「区画」「マップ」は今と同じ分譲地の画面へ。ボタンの色は「詳細」を仕入れ案件と同じ緑に統一（分譲地一覧ページ側の琥珀色はそのまま）。
キーワード検索 仕入れ案件は 案件番号・物件名・所在地、分譲地は PJ番号・PJ名・所在地 を対象に横断検索。
変えないもの サイドバーの「分譲地」と分譲地一覧ページはそのまま残す（分譲地だけを見たいときの導線を維持）。分譲地の新規登録もそちらから。仕入れ案件一覧の「新規登録」は今まで通り仕入れ案件の登録へ。
