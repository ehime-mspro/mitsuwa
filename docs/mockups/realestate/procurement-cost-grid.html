採用額合計（確定優先）:
このモックで試せること
  • 「見込み額を入力」→ 全 17 項目が並び、見込み額の列だけ入力できる。Enter で下へ進む
  • Excel で金額の列（例: 3 行分）をコピー → 「水道」のセルに貼り付け → 水道・解体費・地質調査に順に入る
  • 「確定額を入力」→ 見込み額は灰色で表示だけ。確定額を入れると「差額」が出る（見込みより高いと赤）
  • 確定額の表で、見込み額の無い項目（例: 水道）に確定額を入れて保存 → 見込み額 0 円の行として保存される
  • 役割を「管理者」にして、見込み額の表で保存済みの行（例: 金利負担）を空にして保存 → 「消せるのは経営層だけ」で断られる
  • 見込み額の表で、確定額のある行（例: 仲介手数料）の見込み額を空にして保存 → 断られる
  • 「一般担当」は見るだけ（入力のボタンが出ない。今と同じ）
