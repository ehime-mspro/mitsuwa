契約後工程の横棒（ガント）表示 — 3案比較

対象: 不動産管理の 仕入れ案件 / 分譲地PJ。契約〜決済のあとに走る工程（造成・許認可・測量・販売など）を Excel の工程表のように横棒で見せます。
3案とも 同じ 1 件のデータ（分譲地PJ「余戸南 分譲地」）を描いています。見え方だけが違います。

このモックの前提（違っていたら直します）
・工程名は案件ごとに自由に足す前提です（固定マスタではない）。ここに出ている工程名はサンプルです。
・今日は 2026/08/31 として描いています（赤い破線）。
・データはわざと遅れている状態にしています（造成工事が予定 9/30 → 実績 10/16 見込み）。遅れがどう見えるかを比べるためです。
1 月グリッド・1行1本（Excel の工程表に一番近い）

月の縦線が入ったグリッドに、工程ごとに横棒を 1 本だけ引きます。棒の色は工程の種類（許認可 / 工事 / 測量登記 / 販売）。 契約日・決済日・販売開始のような「点」の予定は ◆ で置きます。一番シンプルで、印刷にも強い方式です。

許認可・申請 工事 測量・登記 販売 マイルストーン（1日の予定）
良い点
  • 見慣れた工程表そのもの。説明不要で読める
  • HTML と CSS だけ。JS ライブラリ 0（外部 CDN も増えない）
  • 行数が増えても素直に伸びる。印刷・PDF 化しやすい
気になる点
  • 遅れているかどうかが分からない（予定と実績が1本に混ざる）
  • 進捗率が出せない。「造成 6 割」のような情報は持てない
2 予定＋実績の 2 段バー（遅れが一目で分かる）

1 工程に対して上に予定（グレーの枠）・下に実績（色つき）の 2 本を引きます。実績が予定からはみ出せば、それがそのまま遅れの長さになります。 右端に「+16日」のように遅れ日数を出します。実績がまだ無い工程は予定だけが出ます。

予定 実績（工事） 実績（許認可） 実績（測量・登記） 赤字 = 予定に対する遅れ日数
良い点
  • 遅れが図でも数字でも出る。経営で見たい情報がここに集まる
  • 「予定どおり終わった工程」も履歴として残る
  • 案1と同じく HTML / CSS だけで作れる
気になる点
  • 1 行が約 2 倍の高さ。工程が 15 行を超えると縦に長い
  • 入力欄が 1 工程あたり 4 つ（予定開始・予定終了・実績開始・実績終了）に増える
3 1本バー＋進捗塗り（コンパクト）

棒は予定の期間で 1 本だけ引き、その中を進捗率で塗りつぶします。塗りが今日線に届いていなければ遅れ。 行の高さが案1と同じまま、進捗まで持てます。左に「済 / 進行中 / 予定 / 遅延」のチップを出します。

予定の期間 進んだぶん（進捗率） 赤い破線 = 今日。塗りが線に届いていなければ遅れ
良い点
  • 案1 と同じ高さのまま進捗が持てる。行が多くても見やすい
  • 入力は「予定開始・予定終了・進捗％」の 3 つで済む
気になる点
  • 進捗％は人が手で入れる主観の数字。更新されないと嘘になる
  • 「いつ終わったか（実績日）」が残らない。過去案件の振り返りに使えない
＋ 工程の入力画面（3案 共通のイメージ・案2の項目で表示）

「案件ごとに工程がバラバラ」なので、行を自由に足す表にします。よく使う工程名は候補から選べて、無ければ直接入力。 並び順はドラッグで入れ替え。この表を保存すると上のガントがそのまま変わります。
