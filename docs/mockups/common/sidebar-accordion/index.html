サイドバー アコーディオン — モック一覧

事業グループをクリックで開閉できるアコーディオン式サイドバー。各ロールでどう見えるかを確認してください。

🎯 主要機能

📂
クリックで開閉: 事業グループ名（▶ アイコン）をクリックで子項目を展開/折りたたみ。スムーズなアニメーション付き。
🎯
現在ページを自動展開: ログイン直後やページ遷移時、URL から判定して該当グループ のみ をデフォルトで展開。
💾
localStorage で状態保持: ユーザーが手動で開閉した状態は次回訪問時にも復元（現在ページのグループは強制展開）。
🏢
ロール別の表示制御: 経営層は全 9 グループ、マネージャーは担当事業のみ、スタッフは担当事業 + ダッシュボードのみ。

📌 確認ポイント

  • グループ開閉: 各グループのヘッダー（▶ アイコン付き）をクリックして開閉が動作するか
  • chevron 回転: 開閉時に ▶ が ▼ に滑らかに 90 度回転するか
  • 展開アニメーション: 子要素が滑らかに表示/非表示されるか
  • 現在ページ強制展開: ロードした直後、現在ページのグループのみ展開されているか
  • localStorage: 任意のグループを開閉 → ページリロード → 状態が保持されるか
  • 「全て折りたたむ」/「全て展開」ボタン: 一括操作が動作するか
  • 「localStorage クリア」ボタン: 状態リセットで現在ページのみが残るか
  • ロール切替リンク: 右上のロール切替で別ロールに遷移しても状態は引き継がれる

⚙️ 実装メモ

  • Alpine.js v3 + @alpinejs/collapse プラグイン（CDN: jsdelivr）
  • 各グループのヘッダーは <button>。@click="toggle('section')"
  • 展開状態は Alpine リアクティブな openSet（Set）で管理
  • 子コンテナは x-show="isOpen(...)" x-collapse でスムーズに開閉
  • CLAUDE.md ルール準拠: <script> 内アロー関数禁止 → function() + var self = this
  • 本実装時は Alpine.store('sidebarGroups') に移行（複数 partial で共有）
