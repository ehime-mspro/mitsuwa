案C 年月選択ピッカー追加

「2025年」「11月」をクリックするとピッカーが展開する方式。
年の範囲：過去10年〜未来1年（2026年現在 → 2016年〜2027年の12年間、4×3グリッドで一覧表示）。
月は12ヶ月すべてを4×3グリッドで表示。今日（2026年4月）は緑ドット、選択中（2025年11月）はグラデーション塗り。

2 年ピッカー展開時
「2025年」をクリック → カレンダー部分が12年一覧に切り替わる。今日の年（2026）は緑枠+ドット、選択中（2025）はグラデーション塗り。

過去10年〜未来1年（2016 - 2027）
  • 4列×3行 = 12年を一画面で俯瞰
  • 年ボタンが active 状態（薄emerald+chevron反転）に
  • ‹ › 矢印は非表示（12年固定なのでスクロール不要）
  • 年をクリックすると自動で通常表示に戻り、その年の同月を表示
3 月ピッカー展開時
「11月」をクリック → 12ヶ月一覧に切り替わる。選択中（11月）はグラデーション塗り。今日（2026年4月）の「月」は表示中の年が一致しないため無印。

  • 4列×3行 = 12ヶ月を一画面で俯瞰
  • 月ボタンが active 状態に
  • 表示中の年が今年（2026）なら今日の月（4月）に緑枠
  • 月をクリックすると自動で通常表示に戻る
遷移フロー
状態1（通常） ─ 「2025年 ▾」をクリック → 状態2（年ピッカー） ─ 年を選択 → 状態1（通常） ※選択年の同月カレンダーを表示
状態1（通常） ─ 「11月 ▾」をクリック → 状態3（月ピッカー） ─ 月を選択 → 状態1（通常） ※選択月のカレンダーを表示
状態1（通常） ─ ‹ または › をクリック → 状態1（通常） ※前後1ヶ月に移動
