# 賃貸マンション管理 要件定義書 v2

## 変更履歴

| 版 | 日付 | 変更内容 |
|----|------|---------|
| v1 | 2026/04/17 | 初版作成 |
| v2 | 2026/04/17 | 駐車場を独立リソースとして追加。`ms_parkings` / `ms_parking_contracts` を新設し、`ms_tenants` に `tenant_type` を追加して外部駐車場利用者に対応。部屋・契約テーブルの `parking_fee` は廃止し、駐車場契約で管理する構造に変更。 |

## 1. 概要

賃貸マンション（自社所有＋管理受託）の物件・部屋・駐車場・入居者・契約を一元管理するモジュール。テナント管理と同じ2階層構造（物件→部屋）を採用しつつ、駐車場は物件に紐付く独立リソースとして管理する。入居者は専用テーブルで管理し、費用体系もマンション向けに設計する。

### 1.1 管理対象

| 項目 | 内容 |
|------|------|
| 管理規模 | 5〜15棟 |
| 所有形態 | 自社所有＋オーナーからの管理受託 |
| 構造 | 物件（マンション棟）→ 部屋（号室）+ 駐車場（部屋とは独立） |

### 1.2 開発スコープ

| # | 機能 | 内容 |
|---|------|------|
| 1 | 物件管理 | マンション棟の登録・編集・一覧・詳細 |
| 2 | 部屋管理 | 号室の登録・編集・ステータス管理 |
| 3 | 駐車場管理 | 物件に紐付く駐車場リソースの登録・編集・ステータス管理 |
| 4 | 入居者管理 | 入居者・外部駐車場利用者の登録・編集（専用テーブル） |
| 5 | 契約管理 | 部屋契約・駐車場契約の新規作成・解約（退去）・賃料改定 |
| 6 | 収支管理 | 棟別・月別の収支合計（賃料＋共益費＋駐車場料） |

### 1.3 スコープ外

| # | 機能 | 備考 |
|---|------|------|
| 1 | 修繕管理 | 別途管理しているため不要 |
| 2 | 入金突合 | 収支合計が分かればOK |
| 3 | 契約更新 | 管理不要 |

## 4. 画面設計

### 4.1 サイドバー配置

```
賃貸マンション          ← 独立グループ（新規追加）
  ├── 物件一覧
  ├── 入居者管理
  ├── 部屋契約一覧
  └── 駐車場契約一覧
```

### 4.2 物件一覧（/mansion/properties）

**フィルターバー:**
- 所有形態（全て / 自社所有 / 管理受託）
- キーワード（物件名）

**テーブル列:**

| # | 列 | 内容 |
|---|-----|------|
| 1 | 物件名 | 物件名（詳細リンク） |
| 2 | 所有形態 | バッジ |
| 3 | 総戸数 | N戸 |
| 4 | 入居率 | 入居中 / 総戸数 × 100% |

> 物件番号・所在地は詳細画面でのみ確認可能。

### 4.3 物件詳細（/mansion/properties/{property}）

**表示内容:**
1. 基本情報（物件名、所在地、構造、築年月、オーナー名等）
2. 稼働サマリー
   - 部屋: 総戸数、入居中、空室、申込み・仮押え、退去予定
   - 駐車場: 総台数、使用中、空き
3. 部屋一覧テーブル（号室、階、間取り、面積、賃料、ステータス、入居者名）
4. **駐車場一覧テーブル**（駐車場番号、月額料金、ステータス、利用者名） **[v2追加]**
5. 収支サマリー（月額: 賃料収入合計、共益費合計、駐車場料合計）

### 4.4 物件登録・編集

**項目:**
- 物件名*、所有形態*、オーナー名（管理受託時）、郵便番号、所在地*
- 総戸数、階数、構造、築年月
- 備考

### 4.5 部屋管理（物件詳細画面内、またはサブ画面）

**部屋の登録項目:**
- 号室番号*、階数、間取り（1K/2LDK等）、専有面積（㎡）
- 募集賃料、共益費、敷金、礼金
- ステータス*

### 4.10 部屋契約登録

**手順:**
1. 物件をセレクトで選択
2. 空室・申込み・仮押えの部屋がセレクトに連動表示
3. 入居者を選択（新規登録リンクあり）
4. 契約情報を入力（契約日、入居日、賃料、共益費、敷金、礼金）
5. **駐車場の紐付け（任意・複数可）**: 該当物件の空き駐車場をチェックボックスで選択 **[v2追加]**
6. 保存時:
   - 部屋ステータスを自動で「入居中」に変更
   - 選択した駐車場について `ms_parking_contracts` を同時作成し、駐車場ステータスを「使用中」に変更

### 4.11 駐車場契約登録（単独） **[v2新規]**

**手順:**
1. 物件をセレクトで選択
2. 空き駐車場がセレクトに連動表示
3. 利用者を選択（`parking_only` 区分で新規登録可）
4. 契約情報を入力（契約日、利用開始日、月額料金、敷金）
5. 保存時に駐車場ステータスを自動で「使用中」に変更

### 4.12 解約処理

**部屋契約の解約:**
- 契約詳細画面から「解約処理」ボタン
- 退去日を入力
- 保存時に部屋ステータスを自動で「空室」に変更、契約ステータスを「解約済み」に変更
- **部屋契約に紐付く駐車場契約も一括解約確認**（個別に残すこともできる） **[v2追加]**

**駐車場契約の解約:**
- 駐車場契約詳細画面から「解約処理」ボタン
- 終了日を入力
- 保存時に駐車場ステータスを「空き」に変更、契約ステータスを「解約済み」に変更

### 4.13 賃料・料金改定

**部屋契約:**
- 契約詳細画面から「賃料改定」ボタン
- 新賃料・新共益費を入力（駐車場は別管理のため対象外）
- 改定日を記録
- `ms_contract_revisions` に履歴保存

**駐車場契約:**
- 駐車場契約詳細画面から「料金改定」ボタン
- 新月額料金を入力
- 改定日を記録
- `ms_parking_contract_revisions` に履歴保存

## 6. テナント管理との主な違い

| 項目 | テナント管理 | マンション管理 |
|------|-----------|-------------|
| 対象 | 商業テナント（店舗・倉庫等） | 賃貸マンション（住居） |
| 入居者 | customers テーブル（法人/個人） | ms_tenants テーブル（個人のみ）。駐車場のみ利用の外部者も含む |
| 費用 | 賃料+共益費+ゴミ代+駆除代+敷金 | 賃料+共益費+敷金+礼金（駐車場は別契約で管理） |
| 駐車場 | なし | 物件に紐付く独立リソース。単独契約も可能 |
| 面積 | 坪数 | 専有面積（㎡） |
| 部屋情報 | 用途区分（店舗/倉庫/事務所等） | 間取り（1K/2LDK等） |
| ステータス | 3種（空室/入居中/商談中） | 4種（空室/入居中/申込み・仮押え/退去予定） |
| 修繕管理 | あり | なし |
| 所有形態 | なし（全て自社所有前提） | 自社所有 / 管理受託 |
| 緊急連絡先 | なし | あり |
| URLプレフィックス | `/tenant/` | `/mansion/` |
