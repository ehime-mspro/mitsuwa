# 運用手順書: 過去の紙の決裁の取り込み

対象: 決裁申請（⑪ 過去の決裁の取り込み。本番: さくらのレンタルサーバ ビジネスプロ）
関連: 要件定義書 `docs/決裁申請_要件定義書_v1.md`（6.4・11 章・16.3 の 1・8・10）、台帳の形 `docs/決裁申請_過去台帳の調査.md`、実装計画 `docs/superpowers/plans/2026-10-08-approval-phase5b.md`

使い始める直前に、決裁の管理者が紙の決裁台帳（年度ごとの Excel）を 1 回取り込むための手順です。画面の文言は「」で書いています。

## 1. いつ行うか

- **紙の申請の受け付けを止め、最後の申請を台帳に書いたあと**、切り替え日より前に行う
  - 紙の台帳の ＮＯ は申請をした時点で書くので、切り替え日に紙で回っている申請にも、もう番号があります。回っている申請の決裁を待たなくてよい
- **試しの申請を片付けたあと**に行う（試す期間に試しの申請が番号を使っていると、取り込みが断られたり、次の番号が食い違ったりします。片付けは段階6b で ⑬ に足す。`docs/運用_受け入れ確認の手引き.md` の 7・8）
- 今年度の台帳を取り込むと、その部門の**次に付く番号**が、取り込んだいちばん大きい番号の次まで進みます（戻りません）
  - ⚠ **取り込まない行の ＮＯ は数えません。** いちばん大きい番号の行が取り込まれないと次に付く番号が足りず、使い始めてからシステムの申請が紙と同じ番号を付けるおそれがあります。**今年度の台帳は「取り込まない行」を 0 件にしてから取り込む**（3.1）
- 台帳は**年度ごとに 1 ファイルずつ**、同じ操作をくり返す（どの順でもよい）
  - 過去の年度の台帳は、次に付く番号を変えません
- 使い始める前（準備中）は、取り込んだ紙の決裁が見えるのは ⑪ の一覧だけです（決裁台帳・紙の決裁の詳細は、使い始めてから見られる人に見えます）。試す期間は、試す人のうちその決裁を見られる人には、決裁台帳と紙の決裁の詳細でも見えます（`docs/運用_受け入れ確認の手引き.md`）

## 2. 先にそろえるもの

### 2.1 部門の管理（⑧）で部門と会社を確かめる

取り込みは、台帳の**シートの名前の先頭の英字**（全角も半角として読む）を、部門の管理の**アルファベット**と照らし合わせます（「Ｊ・住宅」→ J、「ＪＢ・住宅」→ JB）。部門の管理に無いアルファベットのシートは取り込みません。

1. メニュー「決裁の管理」→「部門の管理」を開く
2. 台帳のシートの名前の先頭の英字（08 年度は Ｃ・ＣＢ・Ｓ・ＳＢ・Ｊ・ＪＢ・Ｈ・ＨＢ・Ｍ・ＭＢ・Ｔ・ＴＢ）のうち、**決裁が 1 件でも書いてあるシート**の英字が、どれかの部門の「アルファベット」になっているか確かめる（1〜3 文字。グループ全体で重ならない）
   - 決裁が 1 件も無いシート（08 年度の ＣＢ・ＳＢ・ＨＢ・ＭＢ・Ｔ・ＴＢ）は、部門が無くても取り込みは止まりません（確認の画面のシートの表に「（CB の部門がありません）」と出ますが、「読んだ行」が 0 なら問題ありません）
   - 過去の年度の台帳に、今は無い部門のシートがあれば、その部門も登録する
3. 部門の表の「会社」と、「会社」の表の「期の始まり」が正しいか確かめる（日付の年は、その部門の会社の期の始まりの月で決めます）

> ⚠ **紙の決裁が 1 件でも残っている部門は直せません。** 会社とアルファベットを変えられず、削除もできません。その部門の会社の「期の始まりの月」も変えられません。取り込む前に確かめてください（取り込んだあとに直すには、5.1 で取り消してから）。

- 「今年度の次の番号」は手で入れなくてよい（今年度の台帳を取り込むと進みます）

### 2.2 自分が決裁の管理者になっていること

メニューに「決裁の管理」→「過去の決裁の取り込み」が出ていれば大丈夫です。

### 2.3 台帳のファイル

- `.xls`・`.xlsx` で 10MB まで（08 年度の台帳は約 1.3MB）
- 名前に「08年度」のような年度があると、画面が年度を先に選びます（1〜8 なら令和）
  - ⚠ **平成 1〜8 年度の台帳**は令和の年度が選ばれ、日付の年（1〜8）も合ってしまうので断られません。必ず H の年度に選び直す
  - 2019 年度（令和元年度）の台帳で、日付を「31.05.13」のように平成の年で書いていると、その行は「年（31）が … 年度と合いません」になります → Claude に相談
- 本番の Web のアップロードの上限は測っていません（`~/www/php.ini` の設定は 512M。2026-09-27 に読み取り。サーバーの既定値は 5M・8M）。「台帳のファイルのアップロードに失敗しました。」と出たら Claude に相談（6）

## 3. 取り込みの操作

1. メニュー「決裁の管理」→「過去の決裁の取り込み」→「Excel の台帳から取り込む」
2. 「① 台帳のファイルと年度を選んでアップロードする」で、台帳のファイルを選ぶ
3. 「年度」が台帳の年度になっているか確かめる（08年度 →「R8 年度（2026）」。違うときは選び直す）
4. 「アップロードして内容を確認」を押す。**まだ何も取り込まれません**
5. 「② 取り込む内容の確認」を上から見る（3.1）。金額の控えの行の数も Excel と比べる（3.2）
6. 「取り込む」を 1 回押す（「取り込んでいます…」の間は待つ）

### 3.1 確認の画面で見るところ

| 場所 | 見ること |
|------|---------|
| 件数（「足す」「金額を補う」「すでにある」「取り込まない行」「注意」） | 足す件数が、台帳に書いてある決裁の数と合うか |
| シートの表（シート／種類／部門／読んだ行／足す／すでにある／取り込まない／結び付いた） | 受付簿のシートで「読んだ行」が 1 以上なのに「部門」が「（○ の部門がありません）」なら 2.1 へ（「読んだ行」が 0 のシートは、そう出てもそのままでよい）。種類が「読まない」のシートに決裁が書いてあれば、そのシートは取り込まれない → Claude に相談。**金額の控えのシートは 3.2 で数を比べる** |
| 「取り込むと、今年度の次に付く番号が進みます」 | 今年度の台帳のときだけ出る。「R8-J-001 → R8-J-035」のように、紙のいちばん大きい番号の次になっているか。**なっていなければ「取り込む」を押さず**、Excel を直してアップロードし直す |
| 赤の「取り込まない行が N 件あります…」 | どの行がなぜかが出る（部門が無いシートは、シートごとに 1 つ）。**今年度の台帳は 0 件にしてから取り込む**（1）。過去の年度も、直せるものは Excel を直してアップロードし直す（6 の表）。「日付「…」の年（n）が … 年度と合いません」が何件も出るときは年度の選び間違い → 「取り込む」を押さず、年度を選び直す（一部の 1〜4 月の行は 1 年ずれたまま通ってしまうため） |
| 黄の「確認してください（この N 件は取り込みを止めません）。」 | 読んで、気になれば Excel を直す。取り込み直し（4.1）のときに出る「…は金額がすでにあるので、金額の控えの金額を入れません」「…はすでにあります。Excel と…が違いますが、変えません…」は、そのままでよい |
| 「足す記録（N 件）」 | 決裁No・決裁日・申請者・件名・金額が台帳のとおりか、いくつか見る |
| 「金額の控え（N 行）」の「結び付け先」 | 「R8-J-004（自動）」は自動で結び付いた。**選ぶ欄が出た行**は、「（同じ日付）」が付いた決裁No のうち件名が近いものを選ぶ（同じ日付のものが先に並ぶ）。分からなければ「結び付けない」のまま取り込み、あとで 1 件ずつ金額を入れる（5.2） |

### 3.2 金額の控えの行の数を Excel と比べる（「取り込む」を押す前に）

金額の控えのシート（名前に「金額」が入ったシート）は、次の行を**画面に何も出さずに読み飛ばします**（計算式だけが残った行や見出しの行を読まないため）。

- 日付・申請者・件名のどれかが空の行
- ＮＯ が数でなく、日付も「8.05.13」の形でない行

1. Excel で金額の控えのシートごとに、見出しの行（「日付」「件名」などの文字の行）と合計の行を除き、日付・申請者・件名のどれかが書いてある行を数える
2. 確認の画面のシートの表で、そのシートの「読んだ行」と比べる
3. 「読んだ行」が少なければ、読み飛ばされた行がある → Excel で書き足して保存し、3 の 2 からアップロードし直す

（08 年度の台帳は、2026/10/08 に数えた時点で 20 行とも読めていました。そのあと書き足した行を確かめます）

## 4. 取り込んだあとに確かめること

1. 紙の決裁の一覧に「N 件を取り込みました（金額を補った記録 M 件）。次の番号: 住宅事業部 R8-J-035・…。」と出る（「次の番号」は今年度の台帳のときだけ）
2. 一覧の件数と、下の「取り込みの記録」（取り込んだ日時・ファイル・年度・足した・金額を補った）
3. 部門の管理の「今年度の次の番号」が進んでいる（今年度の台帳のときだけ）
4. 使い始めてから（試す期間なら、試す人の決裁の管理者が）、決裁台帳の「区分」を「紙」にして紙の決裁が並ぶ

### 4.1 回っていた申請の金額をあとで書き足したとき（任意）

同じ年度の台帳をもう一度取り込むと、**契約金額・工事原価・粗利益が 3 つとも空の記録にだけ**、金額の控えの金額を補います。

- 1 つでも入っている記録には補いません（例: 前の取り込みで契約金額だけ入った記録に、あとから書いた工事原価は入らない）→ 5.2 で入れる
- 金額が入っている記録ごとに黄の「…は金額がすでにあるので、金額の控えの金額を入れません」が出ますが、正常です（Excel を直さなくてよい）
- すでにある決裁No の中身は変えません
- 「足す」が 0 件でなければ「足す記録」を見る。5.2 で消した記録や、ＮＯ を直す前の番号も、もう一度足されます。足したくない行は Excel から消してからアップロードする

## 5. 間違えたとき

### 5.1 取り込み 1 回分をまとめて取り消す

1. 「過去の決裁の取り込み」の「取り込みの記録」で、その回の「取り消す（今 N 件・うち手で直した M 件）」を押す
2. 確かめの窓の文を読んで「OK」
   - その回に**足した記録をすべて**消します（そのあと手で直した記録も消えます）
   - **金額を補った記録は、記録も金額も残ります**
   - **次に付く番号は戻りません**。戻すときは、部門の管理でその部門の「今年度の次の番号」を直す（取り消しの知らせの「開始番号」はこの欄）
3. 取り込み直すときは、Excel を直して 3 の 1 から

### 5.2 1 件だけ直す・消す・足す

- 直す: 一覧の決裁No を押す → 直して「直す」（金額だけ入れるときもここ）
- 消す: 同じ画面の「この紙の決裁を削除する」（次に付く番号は戻りません）
- 足す: 一覧の「1 件ずつ登録」（今年度の番号を足すと、次に付く番号が進みます）

## 6. 断られたとき

| 画面の文 | わけ | すること |
|---------|------|---------|
| 「台帳のファイルを選んでください。」・「台帳のファイル（.xls・.xlsx）を選んでください。」 | ファイルを選んでいない・Excel のファイルでない | 台帳のファイルを選ぶ |
| 「台帳のファイルは 10MB までです。」 | ファイルが 10MB を超えている | Claude に相談 |
| 「台帳のファイルのアップロードに失敗しました。」 | 本番のサーバーの上限で断られた、または送る途中で切れた | もう一度アップロードする。続けば Claude に相談 |
| 「Excel のファイル（.xls・.xlsx）として読めませんでした。…」 | 別のファイル・壊れたファイル | 台帳のファイルを選び直す |
| 「台帳の行が多すぎます（すべてのシートで 6,000 行まで）。…」・「1 回に読めるのは 3,000 行までです。…」 | 年度ごとの台帳でない（何年分かをまとめたファイルなど）。または、表から離れた下の行に文字や数が残っている | 年度ごとのファイルにする。年度ごとのファイルなら Claude に相談 |
| 「部門のアルファベット ○ の部門が部門の管理にありません（N 件を取り込みません。…）」 | そのシートの英字の部門が無い | 2.1 で部門を登録し、アップロードし直す |
| 「日付「…」の年（n）が R8 年度と合いません」 | 年度の選び間違い、または台帳の日付の書き間違い | 何件も出るなら年度を選び直す（3.1）。書き間違いなら Excel を直す（年は、選んだ年度か、その日の和暦の年のどちらで書いてもよい） |
| 「日付が空です（件名などが書いてあるのに日付が無い行は取り込みません）」・「日付「…」が読めません（8.05.13 の形で書きます）」・「日付「…」が読めません（ない日付です）」・「日付「…」が今日より先の日付（…）になります」・「日付（…）が R8 年度の期間の外です」・「日付（…）が読めません」 | 台帳の日付の書き漏れ・書き間違い（かっこに「」が無いものは、日付を Excel の日付のセルで入れた行） | Excel を直す |
| 「ＮＯ が空です」・「ＮＯ「…」が 1〜99,999 の数ではありません」 | 台帳の ＮＯ の書き漏れ・書き間違い | Excel を直す |
| 「件名が空です」・「件名が 100 文字を超えています」 | 台帳の件名 | Excel を直す |
| 「同じファイルの中に ○ がもう 1 つあります（…）」 | 同じ部門の同じ ＮＯ が 2 行（どちらも取り込まない） | Excel の ＮＯ を直す |
| 黄の「金額の控えの契約金額「…」が 12 桁までの数ではありません（この行の金額は入れません）」（工事原価・粗利益も） | 金額のセルに小数（式の端数）や文字（「未定」など） | Excel で円の整数にする（直さずに取り込むと、その決裁は金額なしで入る。あとで 4.1 か 5.2） |
| 「金額の控えの結び付けを選び直してください。」 | 金額の控えの 2 行が同じ決裁No を選んでいる、など | 選び直して「取り込む」 |
| 「この確認の画面からは取り込めません（すでに送ったか、画面が古くなっています）。…」 | 「取り込む」の二度押し・ブラウザの戻る | 一覧の「取り込みの記録」で取り込まれたか確かめる。取り込まれていなければアップロードからやり直す |
| 英語の「Page Expired」（419）の画面 | 確認の画面を長い時間開いたままにした | アップロードからやり直す |
| 「取り込む記録がありません（足す決裁No も、金額を補う記録もありません）。」 | もう取り込んである | 一覧で確かめる |
| 「○ はシステムの申請がすでに使っています」・「確認の画面を出したあとで、システムの申請が ○ を使いました。…」 | 試す期間に、試しの申請が番号を使った（または使い始めたあとに取り込んだ） | 紙の台帳は試しの申請を片付けてから取り込む（片付けは段階6b で ⑬ に足す）。それでも起きたら Claude に相談 |
