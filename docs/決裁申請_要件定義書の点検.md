## 調査: 紙の受付簿は部門の中でさらに系統が分かれている（上記 1 の根拠）

`08年度・決裁申請書契約状況.xls` の `ＪＢ・住宅` シートを PhpSpreadsheet で開いて確かめた（2026/09/17）。

```
8.05.13  平井⑤　竹下邸少額工事契約
8.05.22  道後石手菊地邸少額工事契約
8.06.08  古三津Ⅳ④今津邸追加工事契約
8.07.28  新石手②木下邸追加工事契約      … 全 12 件が少額工事・追加工事
```

いっぽう `Ｊ・住宅` の 34 件は売買契約・用地購入・工事発注・広告など通常の決裁で、少額工事は 1 件も無い。
住宅の様式（`住宅・不動産決裁申請書.xls`）が「請負新築工事契約用」と「**追加・少額工事契約用**」の
2 枚組であることと一致する。**Ｊ と ＪＢ は様式の違いで分かれた別々の受付簿**で、連番も独立している。

- `ＭＢ` はシート名が「マンション」で、`Ｍ`（ミツワ不動産）とは事業名そのものが違う。
  **Ｂ が何を指すかは部門ごとに違う可能性が高い**。ほかの Ｂ 系統（ＣＢ・ＳＢ・ＨＢ・ＴＢ）は 08 年度では 0 件で、中身から判断できない
- 16.3 の部門の一覧をいただくときに、系統ごとに確かめる
